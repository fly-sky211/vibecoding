# 数织（Nonogram）游戏 Demo · 无尽模式

纯前端实现的数织小游戏：**无尽模式**自动生成关卡，棋盘从 **9×9 → 12×12 → 15×15** 推进，难度持续递增。支持**涂黑 / 涂白 / 擦除**，某行或某列的黑格全部正确时**自动填充白色**并锁定；**15×15 保证每一行、每一列都至少有一个黑格**。

## 运行

直接用浏览器打开 `index.html` 即可（无需安装、无需服务器；用任意静态服务器托管本目录也可以）。

## 玩法

| 项目 | 说明 |
| --- | --- |
| 无尽模式 | 第 1~10 关 9×9，第 11~25 关 12×12，第 26 关起 15×15，密度与段数随关卡递增 |
| 关卡名 | 通关前显示「？？？」，**通关后才揭晓**图案名（同一关卡图案名固定） |
| 涂黑 / 涂白 / 擦除 | 工具栏切换，或快捷键 `1` / `2` / `3`（也支持 `B` / `W` / `E`） |
| 拖拽涂色 | 按住鼠标/手指拖动可连续涂色 |
| 自动补白 | 某行或某列的黑格与答案完全一致时，自动填充其余白色并锁定（不提示填充数量） |
| 提示变色 | 行/列提示变绿 = 已完成；变红 = 有矛盾（黑格画错位置或白格标错） |
| 进度保存 | 通关数、已揭晓的图案名保存在浏览器 localStorage；已通关关卡可重玩 |
| 15×15 保障 | 生成器保证每个 15×15 关卡每行每列都有黑格 |

## 关卡生成

- 同一关卡编号始终生成**同一谜题**（种子随机数，可复现、可重玩）
- 关卡 = **图案库**程序化绘制（爱心 / 五角星 / 小房子 / 圣诞树 / 小鱼 / …共 18 种，**名字与图案一致**），无任何随机干扰黑格
- 每个尺寸阶段内按图案复杂度从易到难排列；15×15 无尽阶段循环使用全部图案
- 图案横跨/纵贯整个画布，任意尺寸下**每行每列都有黑格**（15×15 硬性要求）
- **保证图案严格符合行列数字**：生成时用回溯求解器验证**唯一解**，不唯一则换图案重试（太阳在 9×9 下不唯一，会被自动跳过）；极端情况下回退到唯一解的下三角模板

## 文件结构

- `index.html` — 页面骨架（选关 / 游戏 / 通关弹窗）
- `style.css` — 样式
- `game.js` — 游戏逻辑（核心判定/自动填充为纯函数，浏览器 UI 独立初始化）
- `generator.js` — 无尽模式关卡生成器（纯函数：种子随机、图案库、难度配置）
- `test.js` — 自检脚本

## 自检

```bash
node test.js
```

校验内容：求解器正确性（唯一解/多解用例）、尺寸与难度映射、图案库与生成关卡质量（数据合法、名字与图案一致、**唯一解**、每行每列都有黑格）、15×15 连续 20 关空行空列硬性检查、前几关互不相同（回归）、生成确定性与性能基准、提示计算交叉验证、自动填充与锁定逻辑（正例 / 负例 / 部分正确 / 矛盾检测）。
