# 数织（Nonogram）游戏 · Beta 版

纯前端实现的数织小游戏 **Beta 版**：**显示全部 60 个关卡，可自由选择任意关卡游玩**（不锁定、不按顺序解锁）。棋盘 9×9 → 12×12 → 15×15，支持**涂黑 / 涂白 / 擦除 / 问号标记**，某行或某列的黑格全部正确时**自动填充白色**并锁定；**15×15 保证每一行、每一列都至少有一个黑格**。

## 运行

直接用浏览器打开 `index.html` 即可（无需安装、无需服务器；用任意静态服务器托管本目录也可以）。

## 玩法

| 项目 | 说明 |
| --- | --- |
| 选关 | 菜单按尺寸分组展示第 1~60 关，**全部可自由点击游玩**，无解锁限制 |
| 关卡名 | 通关前显示「？？？」，**通关后才揭晓**图案名（同一关卡图案名固定） |
| 涂黑 / 涂白 / 擦除 / 标记 | 工具栏切换，或快捷键 `1` / `2` / `3` / `4`（`B` / `W` / `E` / `Q`） |
| 提示 | 💡 按钮或快捷键 `H`：自动填对一个可确定的格子（金色高亮） |
| 拖拽涂色 | 按住鼠标/手指拖动可连续涂色 |
| 错误提示 | 涂错的格子红框高亮，顶部显示「错误 N」计数 |
| 自动补白 | 某行或某列的黑格与答案完全一致时，自动填充其余白色并锁定（不提示填充数量） |
| 提示变色 | 行/列提示变绿 = 已完成；变红 = 有矛盾 |
| 进度保存 | 已通关关卡（含揭晓的图案名）保存在浏览器 localStorage，可随时重玩 |
| 15×15 保障 | 生成器保证每个 15×15 关卡每行每列都有黑格 |

## 关卡结构（Beta 固定 60 关）

| 尺寸 | 关卡 | 说明 |
| --- | --- | --- |
| 9 × 9 | 第 1 ~ 10 关 | 入门 |
| 12 × 12 | 第 11 ~ 25 关 | 进阶 |
| 15 × 15 | 第 26 ~ 60 关 | 挑战 |

（关卡总数在 `game.js` 的 `TOTAL_LEVELS` 常量中调整）

## 关卡生成

- 同一关卡编号始终生成**同一谜题**（种子随机数，可复现、可重玩）
- 关卡 = **图案库**程序化绘制（爱心 / 五角星 / 小房子 / 圣诞树 / 小鱼 / …共 18 种，**名字与图案一致**），无任何随机干扰黑格
- 每个尺寸阶段内按图案复杂度从易到难排列
- 图案横跨/纵贯整个画布，任意尺寸下**每行每列都有黑格**（15×15 硬性要求）
- **保证图案严格符合行列数字**：生成时用回溯求解器验证**唯一解**，不唯一则换图案重试（太阳在 9×9 下不唯一，会被自动跳过）；极端情况下回退到唯一解的下三角模板

## 文件结构

- `index.html` — 页面骨架（全部关卡选关 / 游戏 / 通关弹窗）
- `style.css` — 样式
- `game.js` — 游戏逻辑（核心判定/自动填充为纯函数，浏览器 UI 独立初始化）
- `generator.js` — 关卡生成器（纯函数：种子随机、图案库、难度配置、唯一解求解器）
- `test.js` — 自检脚本

## 自检

```bash
node test.js
```

校验内容：求解器正确性（唯一解/多解用例）、尺寸与难度映射、图案库与生成关卡质量（数据合法、名字与图案一致、**唯一解**、每行每列都有黑格）、15×15 连续 20 关空行空列硬性检查、前几关互不相同（回归）、生成确定性与性能基准、提示计算交叉验证、自动填充与锁定逻辑、错误计数 / 提示选格 / 问号标记（正例 / 负例 / 部分正确 / 矛盾检测）。
